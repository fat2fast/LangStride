# PHP Roadmap

> **Languages**: English | [Tiếng Việt](../../vi/fr/php-roadmap.md)

- **Status**: In Specification
- **Last Updated**: 2026-09-25
- **Scope**: Public MVP (P1)
- **Authority**: Functional Requirement Specification (Canonical)

### FR-PHP-001 — Open roadmap
A learner shall be able to open the PHP learning roadmap. Done when the PHP entry route renders the current roadmap.

### FR-PHP-002 — Structured roadmap data
The roadmap shall be generated from structured data. Done when a roadmap data change is reflected without hard-coding nodes in the view.

### FR-PHP-003 — Learning sections
The roadmap shall contain sections or learning groups. Done when every visible node belongs to a named group.

### FR-PHP-004 — Node prerequisites
Roadmap nodes shall define prerequisites. Done when a node can reference prerequisite nodes or their concepts.

### FR-PHP-005 — Open lesson from node
A learner shall be able to open a lesson from a roadmap node. Done when a node with a published lesson navigates to that lesson.

### FR-PHP-006 — Initial concept coverage
The initial roadmap shall contain approximately 20–30 concepts. Done when the published PHP roadmap covers that target range.

### FR-PHP-007 — Initial complete lessons
The initial release shall contain at least 10 complete lessons. Done when ten published roadmap concepts meet all required lesson content requirements.

### FR-PHP-008 — Planned nodes
Incomplete or planned nodes should be visibly identified. Done when a learner can distinguish a node that cannot yet open a complete lesson.
