# Fix-the-Code Practice

> **Languages**: English | [Tiếng Việt](../../vi/fr/practice-fix-the-code.md)

Status: Planned. Introduced: P3. Release gate: P3. Actor: learner. Depends on FR-PRAC-001 through FR-PRAC-010.

### FR-FIX-001 — Incorrect code
A fix-the-code challenge shall display incorrect code. Done when the learner receives a reproducible faulty snippet or prepared correction choice.

### FR-FIX-002 — Corrected submission
A learner shall submit a corrected answer or choose a correction. Done when the challenge accepts one of its configured answer modes.

### FR-FIX-003 — Deterministic answer validation
The MVP shall support deterministic answer validation. Done when every published fix-the-code challenge has a reproducible expected correction rule.

### FR-FIX-004 — Root-issue explanation
The challenge shall explain the root issue after completion. Done when the explanation identifies the defect, not merely the expected answer.

### FR-FIX-005 — No remote execution
Live remote code execution is not required. Done when all MVP validation works without executing learner code in a remote environment.
