- **Scope**: Product Boundary & MVP Definition

This document defines **WHY** LangStride exists and **WHAT** is explicitly inside vs. outside the Public Repository MVP.

## 1. Problem Statement

Developer technical learning is currently fragmented across roadmaps, fragmented documentation, disjointed algorithm challenge platforms, and mechanical interview questions. 

LangStride unifies technical concept understanding, deliberate practice, error debugging, and cross-language mental model transfer into a single feedback loop.

## 2. Core MVP Learning Loop

```text
Choose Guided Roadmap (PHP)
          ↓
Learn Short Structured Concept
          ↓
Perform Quick Knowledge Check
          ↓
Solve Practice Challenge
          ↓
Review Outcome & Explain Errors
          ↓
Debug & Verify Code
          ↓
Persist Progress Locally
          ↓
Advance to Next Concept
```

## 3. Public MVP Scope (P0 — P5)

The Public Repository MVP is strictly limited to proving the standalone learning loop for PHP:

- **P0**: Repository & Community Foundation (Docs, license, setup, seed workflow).
- **P1**: PHP Knowledge Model & Guided Roadmap (20–30 concepts, 10–15 complete lessons).
- **P2**: Local Learning Progress (Persistent resume, continue learning CTA).
- **P3**: Programming Practice (Multiple choice, predict output, fix the code).
- **P4**: Debugging & AI-Generated Code Review Practice (Static errors, traces, judgment).
- **P5**: Mastery, Review Queue, Full-Text Search, and Public Release.

## 4. Explicit Post-MVP Scope

The following domains represent the long-term vision but are **strictly excluded** from the current delivery scope:

- **Language Expansions**: Full Go roadmap.
- **Language Comparisons**: Version Diff engine, PHP → Go Lang Diff engine.
- **Advanced Tracks**: DevOps Labs, Interactive System Design simulator.
- **Complex Runtimes**: Live cloud execution sandboxes, live remote terminals.
- **AI Integrations**: Model Context Protocol (MCP) servers, autonomous migration agents.
- **Commercial Offerings**: SaaS subscriptions, cloud cross-device sync, Teams, and enterprise RBAC.

Keeping these domains post-MVP ensures the community edition becomes a lightweight, rock-solid, and reliable foundation first.
