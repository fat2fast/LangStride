# Lessons

Status: Planned. Introduced: P1. Release gate: P1; related practice integration gates at P3. Actor: learner and content contributor. Depends on FR-KNOW-005 and FR-KNOW-006.

### FR-LESSON-001 — Concept title
A lesson shall display its concept title. Done when the lesson heading identifies the concept it teaches.

### FR-LESSON-002 — Why it matters
A lesson shall explain why its concept matters. Done when each published lesson contains a learner-facing relevance explanation.

### FR-LESSON-003 — Formatted code examples
A lesson shall support formatted code examples. Done when lesson content can render a readable language-tagged code example.

### FR-LESSON-004 — Common mistakes
A lesson should support a common-mistakes section. Done when an author can provide learner-visible mistakes for a lesson.

### FR-LESSON-005 — Quick check
A lesson should contain a quick knowledge check. Introduced: P1. Release gate: P3. Done when an author can attach a short check without requiring a full practice page.

### FR-LESSON-006 — Related practice
A lesson shall link to related practice. Introduced: P3. Done when a learner can open practice tagged with the lesson concept.

### FR-LESSON-007 — Concept links
A lesson should link to prerequisite and related concepts. Done when the learner can navigate to referenced concepts where material is available.

### FR-LESSON-008 — Git-editable content
Lesson content shall be editable through normal Git contribution. Done when a contributor can change a lesson content file and submit it in a pull request.
