# Content Operations

Status: Planned. Introduced: P0. Release gate: P5. Actor: maintainer. Depends on FR-REPO-009, FR-KNOW-007, and FR-CONT-005.

### FR-ADMIN-001 — Seed/import content
A maintainer shall seed or import repository content. Done when a repeatable documented operation loads repository-owned content into a supported environment.

### FR-ADMIN-002 — Rebuild content indexes
A maintainer shall rebuild content indexes. Done when an explicit supported operation refreshes derived content/search indexes after content changes.

### FR-ADMIN-003 — Set lifecycle status
A maintainer should mark content draft or published. Done when the supported content workflow can transition a content item between its declared lifecycle states.

### FR-ADMIN-004 — No full CMS
A full CMS is not required. Done when all required content operations can be completed through repository content and supported maintenance commands.

### FR-ADMIN-005 — Git source of truth
Git shall remain a supported source-of-truth workflow for educational content. Done when a reviewed repository change can be applied by the documented import or deployment process.
