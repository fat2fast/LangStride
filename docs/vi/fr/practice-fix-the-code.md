# Thực hành sửa lỗi mã nguồn (Fix-the-Code Practice)

> **Ngôn ngữ**: [English](../../en/fr/practice-fix-the-code.md) | Tiếng Việt

- **Trạng thái**: Đang đặc tả (In Specification)
- **Cập nhật lần cuối**: 2026-09-25
- **Phạm vi**: Public MVP (P3)
- **Thẩm quyền**: Đặc tả Yêu cầu Chức năng (Bản dịch tham khảo)

### FR-FIX-001 — Hiển thị đoạn mã bị lỗi
Một bài tập sửa mã phải hiển thị đoạn code có chứa lỗi. Hoàn thành khi người học nhận được một đoạn code lỗi có thể tái tạo hoặc một lựa chọn sửa đổi đã chuẩn bị sẵn.

### FR-FIX-002 — Nộp phương án sửa chữa
Người học phải nộp câu trả lời đã sửa hoặc chọn một phương án chỉnh sửa. Hoàn thành khi thử thách chấp nhận một trong các chế độ trả lời được cấu hình.

### FR-FIX-003 — Xác thực câu trả lời tất định
Phiên bản MVP phải hỗ trợ xác thực câu trả lời tất định. Hoàn thành khi mỗi bài tập sửa mã được xuất bản có một quy tắc chỉnh sửa mong đợi có thể tái lập chính xác.

### FR-FIX-004 — Giải thích vấn đề gốc rễ
Thử thách phải giải thích vấn đề gốc rễ sau khi hoàn thành. Hoàn thành khi phần giải thích chỉ rõ khiếm khuyết trong code chứ không chỉ đơn thuần đưa ra đáp án mong đợi.

### FR-FIX-005 — Không yêu cầu thực thi code từ xa (No Remote Execution)
Không bắt buộc phải có môi trường thực thi code từ xa trực tiếp. Hoàn thành khi tất cả việc xác thực trong MVP hoạt động mà không cần chạy code của người học trên môi trường từ xa.
